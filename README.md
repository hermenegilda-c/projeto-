
# Linux Administration Lab 

# Sobre o projeto 
Este projeto tem como finalidade desenvolver conhecimento praticos sobre o sistema operativo Linux


## Objetivo geral 
Aprender e aplicar tecnicas de administração Linux atraves de exercicios praticos e documentação.



## Objetivos especificos 


-Conhecer os principais comandos Linux. 
-Criar e administrar utilizadores.
-Criar e gerir grupos.
-Configurar permissoes de ficheiros e diretorios.
-Gerir discos e sistemas de armazenamento.
-Configurar e administrar servidores.
-Aprender a utiliar Git e Github.

## Conteudos do projeto

1.Comando Linux
2. Gestão de utilizadores 
3.Permissões e ACL
4.Armazenamento e discos 
5.Administração de servidores 
6.Documentação e exercicios

##Ferramentas utilizadas 
O projeto será desenvolvido atraves de atividades práticcs ,testes de comandos e registto dos resltados 

##Conclusão 

Este laboratório representa um espaço de apresndizagem  desenvolvimento de competencias na area
